How to compare an ACBuy shortlist

  1. Save the exact item. Record the listing ID, seller URL, variant, quoted price and date. Compare shoe measurements in the same units and check chest and length measurements for tops.
  2. Confirm the buying route. Open the CAFANS listing and check the available agent options for that item. Confirm the source listing and selected size before paying.
  3. Review quality-control photos. If available, compare the label, color, visible stitching and any requested measurements with your saved variant. Check the return window before approving shipment.
  4. Compare total cost. Add the item price, domestic delivery, agent fees, international freight and any applicable import costs in one currency. When comparing shipping quotes, use the same packed dimensions, weight and destination.

Frequently asked questions

What is an ACBuy spreadsheet?

It organizes product links and comparison details for shoppers researching an agent order. This edition shows CAFANS catalog picks with reference prices and direct listing links.

Where do the two main buttons go?

Both open the CAFANS homepage. The links in the directory open individual CAFANS product pages.

Does the listed price include delivery?

The directory shows estimated item prices. Check the agent quote for fees and shipping to your destination.
